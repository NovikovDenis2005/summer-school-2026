# Промпты — этап выявления требований

**Инструмент:** Claude Code · модель **Claude Opus 4.8**.

Ниже — промпты, отправленные ИИ на этапе анализа брифа. Приведены дословно.

---

### Промпт 1 — анализ пробелов и противоречий

```
Ты аналитик. Вот сырое письмо заказчика картинг-центра (бриф во вложении).
Бриф намеренно неполный и противоречивый. Найди все пробелы, неоднозначности и
противоречия. Для каждого укажи: цитату/место в брифе, суть проблемы и уточняющий
вопрос заказчику. Сгруппируй по темам (скоуп, слоты/запись, отмена, оценки,
уведомления, авторизация).
```

### Промпт 2 — закрытие пробелов с учётом уточнений к брифу

```
К брифу есть блок уточнений по скоупу с маркерами R-004, R-008, R-015, R-027, R-028.
Раздели мои вопросы на две группы: (1) те, что закрываются этими уточнениями — сошлись
на конкретный R-маркер; (2) те, что остаются открытыми — предложи по каждому
обоснованное допущение аналитика для MVP, помеченное как ДОПУЩЕНИЕ, и явно отметь,
что подлежит подтверждению у заказчика.
```

### Промпт 3 — реестр решений

```
Собери все принятые решения в компактную таблицу: ID (R-xxx для брифа, A-xxx для
допущений), тема, решение, источник, входит ли в MVP. В конце — граница MVP одной
фразой в виде пользовательского пути.
```

### Промпт 4 — открытые вопросы на следующую итерацию

```
Что осталось нерешённым и требует ответа заказчика на следующей встрече? Дай короткий
список конкретных вопросов (не более 5), сфокусированных на том, что реально влияет
на реализацию MVP.
```
