# 2. Основные сценарии MVP (use cases)

Ключевые пользовательские сценарии клиента, включая крайние случаи. Формат:
предусловия → основной поток → альтернативы/исключения. Ссылки на user stories —
в [user-stories.md](user-stories.md).

---

## СЦ-1. Запись на заезд (happy path) — US-01, US-03, US-04

**Предусловия:** есть слоты на ближайшие 7 дней, в выбранном слоте есть свободные карты.

**Основной поток:**
1. Клиент открывает приложение → видит список заездов на 7 дней.
2. Выбирает заезд → открывает карточку с деталями.
3. Выбирает экипировку (своя / прокат).
4. Нажимает «Записаться».
5. Сервер атомарно резервирует карт → бронь создана, свободных картов −1.
6. Клиент видит подтверждение и бронь в разделе «Мои».

**Альтернативы / исключения:**
- **1а.** Слотов нет → empty state «Пока нет доступных заездов».
- **3а.** Прокатный фонд исчерпан → вариант «прокат» недоступен, доступна только «своя».
- **5а. (гонка за последнее место)** Пока клиент оформлял, место занял другой →
  сервер отвечает «Мест уже нет» (409), бронь не создаётся, список обновляется.
- **5б.** Клиент уже записан на этот слот → «Вы уже записаны на этот заезд».

## СЦ-2. Просмотр и фильтрация расписания — US-01, US-02

**Основной поток:**
1. Клиент видит слоты на 7 дней по умолчанию.
2. Задаёт фильтр дат (например, +2 недели) → список обновляется под диапазон.

**Исключения:**
- **2а.** По фильтру ничего нет → empty state.
- Прошедшие слоты не отображаются ни при каком фильтре.

## СЦ-3. Отмена брони клиентом — US-06

**Предусловия:** у клиента есть подтверждённая бронь.

**Основной поток (заранее):**
1. Клиент открывает «Мои» → выбирает бронь.
2. До старта > 60 минут → доступна кнопка «Отменить».
3. Подтверждает → бронь отменена, место возвращается в слот (+1 свободный карт).

**Исключения:**
- **2а. (поздняя отмена)** До старта ≤ 60 минут → кнопка отмены заблокирована,
  показано «Поздняя отмена невозможна, свяжитесь с центром» + телефон.
- Бронь уже завершена/отменена → действие отмены недоступно.

---

## СЦ-4. Отмена заезда центром (погода/форс-мажор) — US-07, R-008

**Триггер:** центр (в своей инфраструктуре) отменяет слот.

**Поток на стороне клиента:**
1. Бронь получает статус **«Отменён центром»** + причина (например, «Гололёд»).
2. Клиенту приходит **push**.
3. В «Моих» бронь видна как отменённая центром, повторная запись на слот запрещена.

---

## СЦ-5. Оценка маршала после заезда — US-08

**Предусловия:** заезд клиента завершён (`completed`).

**Основной поток:**
1. Клиент открывает завершённую бронь → «Оценить маршала».
2. Ставит 1–5 звёзд, при желании пишет комментарий → отправляет.
3. Оценка сохранена, видна в карточке брони.

**Исключения:**
- **1а.** Заезд ещё не завершён → кнопка оценки недоступна.
- **2а.** Оценка уже стоит → повторная отправка отклоняется.

## Карта состояний брони

```
                 (запись)
        ─────────────────────────► confirmed
                                     │  │  │
       (>60 мин: отмена клиентом)    │  │  │  (центр отменил слот)
                 ┌───────────────────┘  │  └────────────────────┐
                 ▼                       │                       ▼
        cancelled_by_client              │              cancelled_by_center
                                         ▼                (push, повтор запрещён)
                              (заезд прошёл: completed)
                                         │
                                         ▼  (оценка маршала 1–5)
                                      rated
```
