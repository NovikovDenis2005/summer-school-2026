# Промпты — этап требований к MVP

**Инструмент:** Claude Code · модель **Claude Opus 4.8**.

---

### Промпт 1 — генерация user stories

```
На основе брифа и реестра решений (decisions.md) сгенерируй user stories для MVP
клиентского приложения картинг-центра, роль Клиент. Сгруппируй в эпики. Для каждой
истории: формат «Как <роль>, я хочу <цель>, чтобы <ценность>», критерии приёмки
списком, приоритет по MoSCoW и статус (реализовано/бэклог). Трассируй истории на
маркеры решений R-xxx / A-xxx.
```

### Промпт 2 — крайние случаи и сценарии

```
Опиши основные сценарии (use cases) с крайними случаями: happy path записи, гонка за
последнее место (двойная бронь), поздняя отмена, отмена центром по погоде, оценка
маршала. Формат: предусловия → основной поток → альтернативы/исключения.
```

### Промпт 3 — карта состояний брони

```
Построй диаграмму состояний брони: confirmed → cancelled_by_client /
cancelled_by_center / completed → rated. Покажи условия переходов (порог 60 минут,
отмена центром, завершение заезда).
```

### Промпт 4 — трассировка

```
Сделай матрицу трассировки user stories на будущие фичи F1–F4 и таблицу бэклога с
причинами, почему истории вне MVP.
```
