# Приложение «Апекс» — код (клиент + API)

Клиентское приложение картинг-центра и API к нему. Роль — **Клиент** (R-028).

```
app/
  server/   Node.js + Express + TypeScript — контракт API, бизнес-логика, тесты
  client/   React + Vite + TypeScript — мобильный клиент
```

## Запуск

Требуется Node.js 20+ (проверено на v24).

```bash
# Терминал 1 — API
cd app/server
npm install
npm start            # http://localhost:4000/api  (health: /api/health)

# Терминал 2 — клиент
cd app/client
npm install
npm run dev          # http://localhost:5173  (проксирует /api → :4000)
```

Открыть в браузере <http://localhost:5173>. Клиент рассчитан на мобильную ширину
(макет ~390px).

## Тесты

```bash
cd app/server
npm test             # Vitest + Supertest: 31 тест
```

## Демо-данные

При старте сервер генерирует расписание на 7 дней и показательные брони демо-клиента:

- **b-1** — завершённый заезд (можно поставить оценку маршалу);
- **b-2** — заезд, стартующий скоро (демонстрирует запрет поздней отмены).

Также в сиде есть слот без свободных мест (сценарий «Мест нет») и слот с пустым
фондом проката (сценарий «прокат недоступен»).

## Демо-сценарии для проверки

1. **Каталог и фильтр** — вкладка «Заезды»; «Фильтр по датам» → выбрать день.
2. **Запись** — открыть заезд → выбрать экипировку → «Записаться».
3. **Отмена** — «Мои брони» → «Отменить» (для заезда > 60 мин до старта).
4. **Оценка** — «Мои брони» → у завершённого заезда поставить звёзды.
5. **Отмена центром (R-008)** — симуляция через dev-эндпоинт:
   ```bash
   curl -X POST http://localhost:4000/api/dev/slots/<slotId>/cancel-by-center \
     -H "Content-Type: application/json" -d '{"reason":"Гололёд"}'
   ```
   Бронь клиента получит статус «Отменён центром» с причиной.

## Перенос на другие брифы

Логика домена не зависит от тематики. Для гончарной/кулинарной студии меняются только
доменные названия и параметры сида (слот заезда → занятие/класс, маршал → мастер/шеф,
карты → круги/рабочие места, лимиты вместимости). Правила брони, отмены, оценки и
контракт API остаются теми же.
