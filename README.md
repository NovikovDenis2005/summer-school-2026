# Картинг-центр «Апекс» — клиентское приложение (учебный проект)

Задание летней школы: пройти полный цикл разработки по одному из брифов в смежных
ролях **аналитик → разработчик → тестировщик**. Выбран бриф **«Картинг-центр»**
([0-brief/brief-karting.md](0-brief/brief-karting.md)).

> Три исходных брифа (картинг / гончарная / кулинария) структурно идентичны — это
> один и тот же e-commerce «запись на слоты» со сменой тематики. Архитектура и код
> ниже переносятся на гончарную/кулинарную заменой доменных названий (слот заезда →
> занятие/класс, маршал → мастер/шеф, карты → круги/рабочие места) без изменения
> логики.

## Скоуп (из уточнений к брифу)

Предмет работы — **только клиентское мобильное приложение и API к нему**, роль
**Клиент** (R-028). Бэкенд, админка и интерфейсы маршала уже существуют и выступают
**black-box источником истины**; гарантия «0 двойных броней» — на его стороне (R-004).
Здесь эта граница закрывается **контрактом API**.

## Инструмент

Все артефакты и код сгенерированы с помощью **Claude Code (модель Claude Opus 4.8)**.
Отправленные промпты приложены в файлах `*-prompts.md` соответствующих папок.

## Как запустить

Требуется Node.js 20+ (проверено на v24). Из папки `app/`:

```bash
# 1. API-сервер
cd app/server
npm install
npm run dev        # http://localhost:4000

# 2. Клиент (в отдельном терминале)
cd app/client
npm install
npm run dev        # http://localhost:5173

# Тесты API
cd app/server
npm test
```

Подробности запуска и демо-сценарии — в [app/README.md](app/README.md).

## Стек

- **Клиент:** React 18 + TypeScript + Vite, мобильная вёрстка (макет ~390px).
- **API:** Node.js + Express + TypeScript, in-memory хранилище с сид-генератором
  расписания на 7 дней.
- **Тесты:** Vitest + Supertest (API).
