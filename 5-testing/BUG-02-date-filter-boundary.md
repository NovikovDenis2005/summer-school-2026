# BUG-02 — Фильтр по дате «съедает» весь выбранный день (off-by-one по границе `to`)

- **Severity:** Major (пользователь видит пустой список при реально существующих заездах)
- **Компонент:** Клиент, `app/client/src/screens/SlotsScreen.tsx`
- **Найден:** при ручном тестировании фильтра дат (TC-06).
- **Статус:** ✅ исправлен и перепроверен.

## Симптом

В фильтре выбрано «С 06.07.2026 По 06.07.2026». Ожидается 3 заезда на 6 июля
(12:00, 15:00, 18:00). Фактически показан empty state **«Пока нет доступных
заездов»**.

Скриншоты — в отчёте по ручной проверке (см. историю сессии): до фикса пусто,
после фикса — 3 карточки.

## Требование / ожидание

US-02: фильтр по датам сужает выборку. Выбор одного дня `06.07–06.07` должен
включать **все заезды этого дня**.

## Причина

Значение из `<input type="date">` — это строка вида `2026-07-06`. Клиент отправлял
её как есть:

```ts
if (to) range.to = new Date(to).toISOString(); // "2026-07-06T00:00:00.000Z"
```

`new Date('2026-07-06')` — это **полночь** (00:00) выбранного дня. Все заезды 6 июля
стартуют в 12:00+ и оказываются **позже** границы `to = 00:00`, поэтому сервер
(`listSlots`: `t <= toMs`) их отфильтровывает. Классический off-by-one по границе даты.

Подтверждение через API:

```
GET /slots?from=...06T00:00Z&to=...06T00:00Z   → slots: 0   (баг)
GET /slots?from=...06T00:00Z&to=...06T23:59Z   → slots: 3   (ожидаемо)
```

## Исправление

Клиент расширяет верхнюю границу до **конца выбранного дня** (23:59:59.999):

```ts
if (to) {
  const end = new Date(to);
  end.setHours(23, 59, 59, 999);
  range.to = end.toISOString();
}
```

Серверный контракт не меняется: `to` остаётся точной меткой времени, ответственность
за «включительно по день» — на UI, который формирует диапазон из выбора дня.

## Промпт (Claude Opus 4.8)

```
Фильтр дат: при выборе одного дня (from=to=2026-07-06) список пуст, хотя заезды в
этот день есть. Причина — input type=date даёт полночь, а слоты позже неё. Предложи
минимальную клиентскую правку, не меняя контракт API.
```

## Проверка после фикса

- Фильтр «06.07–06.07» → показаны 3 заезда 6 июля. ✅
- Дефолтный список и фильтр на дальний период (empty state) — без регрессий. ✅
