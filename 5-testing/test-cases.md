# 5. Тест-кейсы

Проект: клиентское приложение картинг-центра «Апекс». Покрытие: 4 фичи (F1–F4) +
крайние случаи. Часть кейсов автоматизирована (Vitest + Supertest,
`app/server/test/`), часть проверена вручную через UI.

Легенда: **Авто** — есть автотест; **Ручной** — ручная проверка в UI.
Все кейсы на момент сдачи — **PASS** (после починки BUG-01, BUG-02).
