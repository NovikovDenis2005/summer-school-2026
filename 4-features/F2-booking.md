# Фича F2 — Бронирование заезда

**Реализует:** US-04, US-05 · **Требования:** R-004, A-002, A-003
**Статус:** ✅ реализовано и проверено вручную.

## Цель

Клиент записывается на выбранный заезд с выбором экипировки (своя/прокат). Сервер
гарантирует отсутствие двойных броней (R-004): атомарная проверка свободных картов.
Клиент видит свои брони в разделе «Мои».

## Требования (критерии приёмки)

- Выбор экипировки `own`/`rent`; `rent` недоступен при пустом фонде проката (A-002).
- Атомарно: есть свободный карт → бронь создаётся, `freeKarts−1`.
- Нет мест (гонка) → отказ `NO_SEATS`, двойной брони не возникает.
- Повторная запись на тот же слот → `ALREADY_BOOKED`.
- Нельзя записаться на прошедший/отменённый слот → `SLOT_NOT_BOOKABLE`.
- В брони зафиксирована цена на момент записи (A-003).

**Атомарность (AD-2):** проверка `freeKarts>0` и декремент выполняются синхронно,
без `await` между чтением и записью — в однопоточном Node это исключает двойную
бронь. Комментарий — в коде `createBooking`.

## Промпты (Claude Opus 4.8)

```
Реализуй createBooking(userId, slotId, gearOption, now): проверки по порядку —
слот существует, статус scheduled, не начался, нет активной брони клиента, при rent
есть фонд проката, есть свободный карт; затем атомарный декремент freeKarts и
создание брони с зафиксированной ценой. Ошибки: NOT_FOUND, SLOT_NOT_BOOKABLE,
ALREADY_BOOKED, RENT_UNAVAILABLE, NO_SEATS. Эндпоинт POST /bookings и экран записи
с радиовыбором экипировки; при ошибке — понятное сообщение и обновление слота.
```
