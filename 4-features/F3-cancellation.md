# Фича F3 — Отмена (клиентом и центром)

**Реализует:** US-06, US-07 · **Требования:** A-004, R-008
**Статус:** ✅ реализовано и проверено вручную.

## Цель

Клиент может отменить свою бронь, если до старта осталось > 60 минут; поздняя отмена
через приложение запрещена с понятным сообщением. При отмене заезда центром
(погода/форс-мажор) бронь получает статус «Отменён центром» с причиной и push;
повторная запись на такой слот запрещена (R-008).

## Требования (критерии приёмки)

- Отмена клиентом только для `confirmed`; при > 60 мин до старта — успех, `freeKarts+1`.
- При ≤ 60 мин — `LATE_CANCEL`, сообщение «Поздняя отмена невозможна, свяжитесь с центром».
- Отмена центром → статус `cancelled_by_center` + причина + push; слот скрыт из
  каталога; повторная запись → `SLOT_NOT_BOOKABLE`.

## Реализация

| Слой | Файл |
|------|------|
| Домен — клиентская отмена | [booking.ts](../app/server/src/domain/booking.ts) `cancelBooking()` |
| Домен — отмена центром | [booking.ts](../app/server/src/domain/booking.ts) `cancelSlotByCenter()` |
| Эндпоинты | [routes.ts](../app/server/src/http/routes.ts) `POST /bookings/:id/cancel`, `POST /dev/slots/:id/cancel-by-center` |
| Клиент | [BookingsScreen.tsx](../app/client/src/screens/BookingsScreen.tsx) |

Порог отмены — `LATE_CANCEL_MINUTES = 60` в
[store.ts](../app/server/src/store/store.ts). Клиент дублирует порог для UX
(показывает либо кнопку «Отменить», либо сообщение), сервер — источник истины.

> Отмена центром — действие внешней инфраструктуры (вне клиентского контракта),
> вынесена в **dev-эндпоинт** как симуляция (AD-5).

## Промпты (Claude Opus 4.8)

```
Реализуй cancelBooking(userId, bookingId, now): только confirmed (иначе
NOT_CANCELLABLE), если до старта <= 60 мин — LATE_CANCEL, иначе отмена и возврат
места. И cancelSlotByCenter(slotId, reason): слот -> cancelled_by_center, его
активные брони -> cancelled_by_center с причиной + push-лог. На клиенте: для
confirmed показывать кнопку отмены либо сообщение о поздней отмене; для отменённых
центром — бейдж и причину.
```
