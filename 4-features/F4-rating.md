# Фича F4 — Оценка маршала

**Реализует:** US-08 · **Требования:** A-005
**Статус:** ✅ реализовано и проверено вручную.

## Цель

После завершённого заезда клиент ставит маршалу оценку 1–5 звёзд с необязательным
комментарием. Оценка одна на бронь; средний рейтинг маршала пересчитывается.

## Требования (критерии приёмки)

- Оценка доступна только для брони со статусом `completed` (иначе `NOT_COMPLETED`).
- `stars ∈ [1..5]` целое (иначе `INVALID_RATING`).
- Одна оценка на бронь (повтор → `ALREADY_RATED`).
- После отправки оценка видна в карточке брони; рейтинг маршала обновлён.

## Реализация

| Слой | Файл |
|------|------|
| Домен | [booking.ts](../app/server/src/domain/booking.ts) `rateBooking()`, `recomputeMarshalRating()` |
| Эндпоинт | [routes.ts](../app/server/src/http/routes.ts) `POST /bookings/:id/rating` |
| Клиент — форма и звёзды | [BookingsScreen.tsx](../app/client/src/screens/BookingsScreen.tsx) `RatingForm`, [StarRating.tsx](../app/client/src/components/StarRating.tsx) |

**Производный статус (AD-3):** `completed` вычисляется на лету — бронь `confirmed`,
слот которой уже закончился. Отдельного планировщика нет.

## Промпты (Claude Opus 4.8)

```
Реализуй rateBooking(userId, bookingId, stars, comment, now): валидация stars 1..5,
только для завершённого заезда (производный статус completed = confirmed + слот
закончился), одна оценка на бронь, пересчёт ratingAvg/ratingCount маршала. Эндпоинт
POST /bookings/:id/rating. На клиенте — компонент звёзд и форма оценки в карточке
завершённой брони; после отправки показать оценку read-only.
```
