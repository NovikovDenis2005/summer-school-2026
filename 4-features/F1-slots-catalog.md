# Фича F1 — Каталог заездов

**Реализует:** US-01, US-02, US-03 · **Требования:** R-027, A-001
**Статус:** ✅ реализовано и проверено вручную.

## Цель

Клиент видит список доступных заездов на ближайшие 7 дней, может отфильтровать по
датам и открыть карточку заезда с деталями. Прошедшие и отменённые слоты не
показываются; при отсутствии заездов — понятный empty state.

## Требования (критерии приёмки)

- По умолчанию — слоты на ближайшие 7 дней (R-027).
- Прошедшие слоты (старт ≤ сейчас) скрыты; отменённые центром — скрыты.
- Фильтр по датам `from`–`to`, может выходить за 7 дней.
- Empty state «Пока нет доступных заездов».
- Карточка: время, конфигурация трассы, маршал+рейтинг, свободные места, цена,
  адрес, место сбора, цена проката.

## Реализация

| Слой | Файл |
|------|------|
| API — фильтрация | [app/server/src/domain/slots.ts](../app/server/src/domain/slots.ts) `listSlots()` |
| API — эндпоинты | [app/server/src/http/routes.ts](../app/server/src/http/routes.ts) `GET /slots`, `GET /slots/:id` |
| Клиент — список | [app/client/src/screens/SlotsScreen.tsx](../app/client/src/screens/SlotsScreen.tsx) |
| Клиент — карточка | [app/client/src/screens/SlotDetail.tsx](../app/client/src/screens/SlotDetail.tsx) |

Ключевое: `listSlots` фильтрует `status==='scheduled'`, `старт ≥ now`, окно
`[from, to]` (дефолт `to = now + 7 дней`), сортировка по времени.

## Промпты (Claude Opus 4.8)

```
Реализуй каталог слотов: доменная функция listSlots(all, now, from?, to?) —
только scheduled, скрыть прошедшие, дефолтное окно 7 дней, сортировка по startsAt.
Эндпоинт GET /slots с query from/to и GET /slots/:id. На клиенте — экран списка с
мобильными карточками, фильтром дат и empty state «Пока нет доступных заездов».
```
